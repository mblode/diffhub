title: Diff Views
description: Review your uncommitted changes by default, or switch the scope to your whole branch against the base branch.
---

## Split vs unified

Toggle between split and unified views with the `s` key or the layout toggle in the status bar.

- **Split** - side-by-side view with the old file on the left and the new file on the right
- **Unified** - one stream of additions and deletions inline

## Diff scopes

Pick the scope from the status bar. DiffHub remembers your choice in the browser.

- **Touched** (default) - all uncommitted work against `HEAD`: staged and unstaged changes, plus untracked files.
- **All** - everything your branch changed since it diverged from the base branch, including uncommitted work. Use it before you push, or when the agent already committed its work.
- **Committed** - only the commits on this branch against the base branch.
- **Staged** - only staged changes against `HEAD`.
- **Unstaged** - only unstaged changes to tracked files.

## Merge-base diffing

The **All** and **Committed** scopes diff against `git merge-base HEAD <base-branch>`.

That means commits pushed to the base branch after you branched do not show up in the review. You only see what your branch changed.
